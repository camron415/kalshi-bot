# Getting Started

Welcome to the Kalshi Predictive Trading Bot!

This guide will help you set up and run the bot for Kalshi-only predictive trading using AI and external data.

## Prerequisites
- Rust toolchain (https://rustup.rs)
- Kalshi API key
- xAI (Grok-4) API key
- NewsAPI key

## Quick Start
1. Clone the repository and enter the project directory.
2. Copy `.env.example` to `.env` and fill in your API keys.
3. Build and run:
   ```sh
   cargo build --release
   cargo run --release
   ```

For more details, see the README and other docs.
